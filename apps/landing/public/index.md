# KŌMA Studio

KŌMA Studio is free and open-source (MIT) scanlation software for manga, manhwa, and comics.
It is a self-hostable desktop app, not a hosted service.

## Core workflows

- translate chapters with AI assistance
- clean bubbles and redraw art
- typeset dialogue and SFX
- review chapter outputs before release

## Licensing and deployment

- License: MIT — commercial use, forks and redistribution allowed
- Free forever: no paid tier, no credits, no paywalled features
- Runs on the user's machine: no account, no license server, no usage telemetry
- Bring your own model: OpenAI, Anthropic, Gemini, or a local OpenAI-compatible endpoint
- Platforms: Windows, macOS, Linux — or build it from source
