# KOMA Studio Scanlation Workflow

Use this skill when an agent needs a concise overview of how KOMA Studio is typically used.

## Licensing

KOMA Studio is free and open-source software under the MIT license. It runs on the user's
machine with no account, no usage telemetry, and no paid tier. AI features require the user's
own provider credentials (OpenAI, Anthropic, Gemini, or a local OpenAI-compatible model).

## What KOMA Studio does

- translate manga, manhwa, and comics
- clean speech bubbles and redraw covered art
- typeset dialogue and SFX
- review outputs before chapter release
